Wiki Monster Hunter

Ver página web

Wiki Colaborativa

Este proyecto es una wiki especializada en Monster Hunter, desarrollada con Spring Boot y Angular. Implementa autenticación con AWS Cognito (incluyendo login con Google), microservicios registrados en Eureka Server, principios SOLID, uso de DTOs para separar la lógica de negocio y documentación interactiva con Swagger.

En el backend se han utilizado Lombok para reducir código repetitivo, JPA/Hibernate para el mapeo de entidades y Postman para la validación de endpoints. Además, se aplicaron patrones de diseño para lograr una arquitectura mantenible y escalable.

El frontend consume los endpoints mediante services, aplicando un diseño modular con componentes reutilizables y modelos tipados en TypeScript. La interfaz está optimizada con Ionic para ofrecer una experiencia responsiva en dispositivos móviles y escritorio.

El despliegue se realizó en AWS utilizando instancias EC2 para el backend y RDS como base de datos, con el frontend publicado en Netlify. La gestión del dominio y certificados SSL se configuró con Cloudflare.
