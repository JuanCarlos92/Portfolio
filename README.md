# Portfolio Personal - Juan Carlos Filter Martín

Este es mi **Portfolio Personal**, desarrollado para mostrar mis proyectos, habilidades y servicios como Desarrollador FullStack. El sitio está diseñado con un enfoque moderno, responsive y visualmente atractivo.

## 🚀 Tecnologías utilizadas

- **Frontend**: [Astro](https://astro.build/) para generación de sitios estáticos.
- **HTML & CSS**: Estructura semántica y estilos personalizados.
- **JavaScript**: Funcionalidades dinámicas como menú responsive y envío de emails mediante [EmailJS](https://www.emailjs.com/).
- **Fuentes e iconos**: Google Fonts (Montserrat) y Font Awesome.
- **Control de versiones**: Git y GitHub.

## 🗂 Estructura del proyecto

```
Portfolio/
├─ public/
│  ├─ img/           # Imágenes usadas en el sitio
│  └─ favicon.svg
├─ src/
│  ├─ components/    # Componentes reutilizables (Header, Footer, Secciones)
│  ├─ layouts/       # Layout principal del sitio
│  ├─ pages/         # Páginas del sitio (index.astro)
│  └─ styles/        # Archivos CSS
├─ package.json
├─ astro.config.mjs
└─ README.md
```

## 🌐 Características

- Menú de navegación fijo y responsive.
- Secciones: Inicio, Sobre mí, Servicios, Portfolio y Contacto.
- Integración con EmailJS para enviar mensajes desde el formulario de contacto.
- Diseño completamente responsive para móviles, tablets y escritorio.

## 📦 Instalación y ejecución local

1. Descargar el proyecto.
2. Instalar dependencias:

```bash
npm install
```

3. Iniciar el servidor de desarrollo:

```bash
npm run dev
```

4. Abrir el navegador en [ http://localhost:4321](http://localhost:4321)
